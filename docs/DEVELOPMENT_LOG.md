## CEL-013 Pass 2B.1 — Synthetic grouped recording coordinator

- Added `GroupedRecordingCoordinator` around the existing schema-v3 grouped repository. It has independent bounded queues per child stream, stream-local arrival sequences, host monotonic elapsed times, separate read-failure records/counters, queue/rejection/high-water snapshots, fair bounded batches, and a single SQLite writer thread. - Grouped repository writes now require the exact owner token while a database lease exists. Lease checks and grouped writes run inside `BEGIN IMMEDIATE` transactions. Final group finalization and matching lease release are one transaction. Old-looking leases are never automatically stolen. The existing v2 single-camera recorder still does not acquire this v3 lease; production integration must coordinate both recording paths before they may share a database.
- Queue-full behavior rejects the current timing record, counts the loss, preserves the assigned frame sequence gap, and continues attempting later records. There is no automatic retry, resume, stale-lease recovery, or false completion.
